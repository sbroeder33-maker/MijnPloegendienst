# Mijn Ploegendienst — echte Android app

Native Android-project (Java), portretmodus, donker haven-thema, eigen kraan-icoon, dashboard, uren invoeren, maandoverzicht en instellingen. Gegevens worden lokaal op de telefoon opgeslagen.

## Inbegrepen
- Dagdienst 130%
- Avond 150%
- Zaterdag 150%
- Nacht 200%
- Zondag 200%
- Basisloon €4.480,49
- Uurloon €26,68
- Schematoeslag 15,06%
- BHV/EHBO €12,50
- Netto vergoeding €118,45
- Netto schatting gebaseerd op de aangeleverde salariswijzer; aanpasbaar in Instellingen.

## APK bouwen
Open deze map in Android Studio. Kies **Build > Build APK(s)**. De APK verschijnt daarna onder `app/build/outputs/apk/debug/`.

Dit project is bewust zonder externe UI-library gebouwd, zodat het klein en eenvoudig te bouwen blijft.
